Portfolio

Personal portfolio website built with React, TypeScript, and Vite.

Overview

This project showcases my skills, experience, and web development projects. It is designed to be fast, responsive, and accessible across different devices and screen sizes.

Built With
React
TypeScript
Vite
Getting Started
Prerequisites

Make sure you have the following installed:

Node.js (v18 or later recommended)
npm

You can verify your installation with:

node -v
npm -v
Installation

Clone the repository:

git clone https://github.com/M-Araujo/portfolio.git

Navigate to the project directory:

cd portfolio

Install dependencies:

npm install
Running the Development Server

Start the local development server:

npm run dev

The application will be available at:

http://localhost:5173
Building for Production

Create an optimized production build:

npm run build
Previewing the Production Build

Preview the production build locally:

npm run preview
